Common Questions

Frequently asked questions

Everything you need to know about CodeLabX. Can't find what you're looking for? Reach out.

Does CodeLabX currently have billing?
No billing flow exists in the current development build. Public availability, future pricing, and AI-provider costs are not promised. AI features also require server configuration and are subject to quotas.
What programming languages and topics are supported?
Roadmap creation currently offers two maintained tracks:
  • Machine Learning
  • Data Structures & Algorithms
Free-form AI tools may discuss other topics when they are enabled, but generated material can be incomplete or incorrect.
Do I need any prior coding experience?
Absolutely not! CodeLabX is designed for learners at all levels. When you create a roadmap, you can choose from three difficulty levels:
  • Beginner: Perfect if you're just starting out
  • Intermediate: For those with some coding background
  • Advanced: Deep dive into complex topics
Roadmaps use your selected duration, study time, and level. Generated lessons provide additional AI-assisted explanations.
How does the AI code review work?
The AI Code Examiner sends submitted code to Google Gemini and returns a sanitized explanatory review. Depending on the response, it may identify potential issues, suggest improvements, discuss complexity, or propose alternatives. It does not execute the code and its feedback is not a correctness verdict. The result is AI-generated guidance, not executed or independently verified code.
Is my code and data private and secure?
CodeLabX uses owner-scoped access controls for private learning data.
  • Passwords are handled by Django's password hashing system
  • Profiles can be public or private
  • AI prompts, code, and images are sent to Google Gemini only when an AI feature is used
  • You can export or permanently delete your account from Settings
  • Uploaded images are validated and normalized before processing
Review the Privacy page for the current data-processing summary.
Can I use CodeLabX on mobile devices?
CodeLabX uses responsive layouts intended for:
  • Desktop computers
  • Laptops
  • Tablets
  • Mobile phones
When the site is deployed, signed-in progress is stored on that deployment and can be accessed through a supported browser. There is no native mobile app today.
