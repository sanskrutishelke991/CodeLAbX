Privacy summary

Last updated: August 2026. This page describes the current development version of CodeLabX.

Stored data

CodeLabX stores account details, profile information, learning progress, assessments, notes, bookmarks, chat history, uploaded image metadata, badges, and XP events.

AI processing

When you use an AI feature, the relevant prompt, code, question, or normalized image is sent to Google Gemini for processing. Do not submit secrets or highly sensitive personal information.

Visibility

Private user-owned records are scoped to their owner. Public profile and leaderboard visibility follows the profile visibility setting.

Your controls

Settings provides profile visibility, password reset, JSON data export, and permanent account deletion.

Local development

This repository currently uses SQLite and local media for development. Production storage and retention controls must be configured before public deployment.
